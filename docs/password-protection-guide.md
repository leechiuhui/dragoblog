# 🔒 密碼保護功能使用指南

本部落格支持為文章設置密碼保護，讓您可以控制特定內容的訪問權限。

## 🚀 快速開始

### 1. 設置文章密碼

在您的markdown文章的frontmatter中添加 `password` 字段：

```yaml
---
title: 我的私密文章
date: 2025-06-08
password: "您的密碼"
---
```

### 2. 保護文章內容

使用 `<PasswordProtected>` 組件包裹需要保護的內容：

```markdown
# 我的私密文章

這部分內容是公開的，所有人都可以看到。

<PasswordProtected>

## 受保護的內容

這裡的內容需要輸入密碼才能查看：

- 私人想法
- 敏感資訊
- 付費內容

</PasswordProtected>

這部分內容又是公開的了。
```

## ✨ 功能特點

- **🔐 安全保護**：內容在密碼驗證前不會顯示
- **💾 智能記憶**：瀏覽器會記住驗證狀態，下次訪問無需重新輸入
- **🔄 靈活控制**：可以隨時重新鎖定內容
- **📱 響應式**：完美適配手機、平板和桌面設備
- **🌙 深色模式**：自動適配深色主題
- **🏷️ 視覺標識**：側邊欄中會顯示🔒圖標標識受保護文章

## 📋 完整示例

```markdown
---
title: 🔒 我的秘密日記
date: 2025-06-08
author: DragoBlog
category: 個人
description: 這是我的私人日記
password: "mySecret123"
tags:
  - 日記
  - 私密
---

# 🔒 我的秘密日記

<PostMeta />

今天天氣很好，我想記錄一些特別的事情...

<PasswordProtected>

## 真正的秘密

這裡記錄了我不想公開的想法和經歷：

1. 今天遇到的尷尬事件
2. 對某個人的真實看法
3. 未來的秘密計劃

### 重要決定

經過深思熟慮，我決定...

</PasswordProtected>

感謝閱讀我的日記！
```

## ⚠️ 安全性提醒

這是一個**前端密碼保護**方案，具有以下特點：

### ✅ 適用場景：
- 個人博客的私密內容
- 朋友圈分享的半私密內容
- 草稿文章的臨時保護
- 付費內容的基礎保護

### ❌ 不適用場景：
- 高度敏感的商業資料
- 個人隱私資訊（身份證、密碼等）
- 需要企業級安全的內容
- 法律相關的機密文件

### 🔍 技術說明：
- 密碼會出現在網頁的源代碼中
- 有經驗的用戶可以透過開發者工具查看
- 這是一種"禮貌性"的保護，而非軍事級加密

## 🛠️ 進階配置

### 自定義密碼提示

可以在frontmatter中添加自定義提示：

```yaml
---
title: 我的文章
password: "123456"
passwordHint: "我的生日（6位數字）"
---
```

### 批量管理

對於多篇需要相同密碼的文章，建議：

1. 使用統一的密碼策略
2. 在文件名中添加標識（如 `private-` 前綴）
3. 定期更新密碼

## 💡 使用建議

1. **密碼選擇**：使用容易記住但不太常見的密碼
2. **內容規劃**：在文章開頭說明哪些部分是受保護的
3. **備份管理**：保留密碼記錄，避免忘記
4. **定期檢查**：確保保護功能正常運作
